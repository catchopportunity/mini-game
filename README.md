# Mini Games

빌드 없이 각 HTML 파일을 브라우저에서 열면 바로 플레이 가능.

## Neon Breaker (`index.html`)

작은 벽돌깨기 게임.

- ← → 또는 마우스로 패들 이동
- SPACE 또는 클릭으로 발사/시작
- 레벨마다 벽돌 줄 수와 공 속도 증가
- BGM과 벽/패들/벽돌 충돌음, 레벨업/게임오버 효과음 포함 (전부 코드로 합성한 사운드, 외부 음원 파일 없음). HUD의 🔊 버튼으로 음소거

## Neon Marble (`bluemarble.html` + `bluemarble.css` + `bluemarble.js`)

봇과 1:1로 겨루는 부루마블(모노폴리류) 게임. 11×11, 40칸의 큰 보드에 세계 도시 7개 그룹(동남아 → 서울/뉴욕급 최고가)이 배치되어 있다. HTML/CSS/JS가 파일로 분리되어 있지만 빌드는 여전히 필요 없음 — `bluemarble.html`만 열면 나머지를 자동으로 불러온다.

- 시작 자금은 플레이어가 크게 불리함 (플레이어 100만원 / 봇 1000만원), 출발점 통과 시 급여 500만원
- 주사위를 굴려 이동, 빈 도시는 매입, 남의 도시는 통행료 지불
- 플레이어가 주사위를 굴리면 은근슬쩍 ±1칸 범위에서 가장 유리한 결과로 조정될 수 있음 (겉보기엔 정상 굴림). 자금이 넉넉할 땐 거의 개입 안 하다가, 파산에 가까워질수록(현금 150만원 아래) 개입 확률이 급격히 커짐
- 각 칸에 현재 통행료가 항상 표시되고, 소유·건설 단계는 칸 오른쪽 위의 배지로 보여줌
- 건설은 그 도시에 도착할 때마다 딱 한 단계씩만 가능(빈 땅→별장→빌딩→호텔), 그룹 4개를 모두 가져야 지을 수 있음. 지을수록 비용도 커지고, 통행료는 그룹독점 2배 → ★1 4배 → ★2 8배 → ★3 16배로 가파르게 상승
- 그룹(색깔) 4개를 모두 모으면 축하 연출이 뜨고, 그 그룹 도시들은 보드에서 계속 그룹 색으로 빛남
- 랜드마크는 도시마다 이름과 아이콘이 다름(예: 파리→에펠탑🗼, 뉴욕→자유의 여신상🗽, 카이로→기자 피라미드🔺 등 28개 도시 전부 고유). 호텔까지 지은 뒤 보드를 한 바퀴 더 돌아 그 땅에 다시 착지하면 건설 가능 — 통행료가 30배로 최고치가 되고, 이후로는 상대가 인수할 수 없음
- 상대 소유의 땅(랜드마크 제외)에 걸리면 통행료만 낼지, 투자금의 2배를 내고 강제로 인수(소유권+건물째 매입)할지 선택 가능
- 우측 상단 헤더의 📜 규칙 버튼으로 전체 규칙을 언제든 확인 가능
- 황금열쇠 칸(3개)은 카드가 반짝이며 튀어나오는 연출과 함께 결과가 공개됨. 카드 종류도 16가지로 다양함 — 상대에게 돈을 뜯거나 뜯기는 카드, 세금 면제권, 카드를 한 번 더 뽑는 찬스, 보유 현금 비례 이자/벌금, 도시 무료 업그레이드 쿠폰 등
- 황금열쇠 자리 중 3칸은 각기 다른 특수 칸으로 대체됨:
  - 🏪 복리 상가: 매입 가능, 방문자가 통행료를 낼 때마다 다음 통행료가 2배로 뛰는 땅 (최대 32배까지)
  - 📈 투자 신탁: 매입 가능, 통행료는 없지만 소유주가 출발점을 통과할 때마다 배당금을 받음
  - 🎰 카지노: 도착하면 즉석에서 보유 현금 일부를 자동으로 베팅해 꽝/2배/3배/잭팟(6배) 중 하나가 걸림
- 세금 칸은 2개뿐이고, 금액은 고정이 아니라 (현금 + 보유 부동산 가치)의 10% — 자산이 많을수록 더 많이 냄
- 세금·황금열쇠 페널티는 중앙기금에 적립되며, 중앙기금 칸에 도착하면 전액 획득, 출발점을 통과할 때도 쌓인 중앙기금의 20%를 급여에 얹어서 자동으로 나눠줌
- 우측 상단 코너는 순간이동(🌀) 칸 — 보드 위 무작위 칸으로 워프되어 그 칸의 효과가 바로 적용됨
- 더블 3연속이나 황금열쇠에 걸리면 무인도(감옥)로 이송
- 자금이 부족하면 보유 자산을 자동 매각, 그래도 부족하면 파산으로 게임 종료
- 봇은 여유 자금을 남기며 매입/건설을 자동 판단
- BGM과 주사위·매입·통행료·황금열쇠·카지노·독점·랜드마크·파산 등 상황별 효과음 포함 (전부 코드로 합성한 사운드, 외부 음원 파일 없음). 헤더의 🔊 버튼으로 음소거
